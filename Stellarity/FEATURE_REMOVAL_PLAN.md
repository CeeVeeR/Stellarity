## Stronghold Removal Plan

### Files to Remove

#### Worldgen and Structure
- data/minecraft/worldgen/structure/stronghold.json — Defines the stronghold structure for world generation.
- data/stellarity/tags/worldgen/structure/stronghold.json — Tags for worldgen structure inclusion.
- data/stellarity/predicate/location/in_structure/stronghold.json — Predicate for detecting if an entity or player is in a stronghold.
- data/stellarity/worldgen/processor_list/stronghold_generic.json — Structure processor for stronghold pieces.
- data/stellarity/item_modifier/stronghold_armor_trim.json — Item modifier for stronghold-related loot.
- data/stellarity/worldgen/structure/old_stronghold.json — Possibly an old or alternate stronghold structure definition.
- data/stellarity/structure/stronghold/ — All .nbt files (e.g., farm.nbt, prison.nbt) — Structure pieces for the stronghold.

#### Loot Tables
- data/stellarity/loot_table/stronghold/ — All .json files (e.g., farm.json, junk.json) — Loot tables for stronghold chests and mobs.

#### MCFunction Files
- data/stellarity/function/mob/stronghold/buff_illagers.mcfunction — Buffs illager mobs in strongholds.
- data/stellarity/function/mob/stronghold/buff/evoker.mcfunction — Buffs evoker in strongholds.
- data/stellarity/function/mob/stronghold/buff/witch.mcfunction — Buffs witch in strongholds.
- data/stellarity/function/mob/stronghold/buff/vindicator.mcfunction — Buffs vindicator in strongholds.
- data/stellarity/function/mob/stronghold/buff/pillager.mcfunction — Buffs pillager in strongholds.
- data/stellarity/function/mob/stronghold/buff/illusioner.mcfunction — Buffs illusioner in strongholds.
- data/stellarity/function/mob/stronghold/buff/vindicator_elektra_shield.mcfunction — Special buff for vindicator (referenced by vindicator buff).

#### Function Callers
- data/stellarity/function/loop/timed/5_second.mcfunction — Calls buff_illagers for raiders in strongholds.

### Summary and Dependencies
- All above files are directly related to the stronghold structure, its mobs, loot, and worldgen.
- The main dependency is the call in loop/timed/5_second.mcfunction, which should be edited to remove or skip the stronghold logic after removal.
- Removal of these files will eliminate the stronghold from worldgen, loot, and mob behavior.

### Next Steps
1. Remove or backup all listed files.
2. Edit loop/timed/5_second.mcfunction to remove or comment out the call to mob/stronghold/buff_illagers.
3. Test the datapack to ensure worldgen and other features still work.
